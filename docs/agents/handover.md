## 2026-10-06 学生のログイン番号を K01・S21 の形に

**決めたこと**

- 学生はログイン時に、国際ビジネス科は K＋学籍番号の下2桁、総合ビジネス科は S＋下2桁で入れる。学籍番号そのものは変えず、学籍番号でも入れる
- 学生詳細の「ログイン」にその学生の番号が出る。本番に公開済み（同じ URL）

**次にやること**

- 利用者が本番で K01 などの番号で入れるか試す
- 利用者が管理画面で自分のIDとパスワードを変え、マイドライブに「ShiftDB バックアップ」ができたか確かめる
- この枝の変更を main に取り込む

**未解決の問題**

- 本番のクラス名に「国際」「総合」が入っているかは画面で確かめていない（入っていなければ短い番号では入れない）
- 同じクラスで下2桁が重なる学生がいると、その番号では入れない（学籍番号で入る）
