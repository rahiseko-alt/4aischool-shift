## 2026-10-01 生徒・管理画面の細かい直しと、言語・祝日・8時間ロックを追加

**決めたこと**

- 言語は7つ（ja・ne・vi・en・my・si・bn）。切り替えは選択欄。スリランカはまずシンハラ語
- 日本の祝日（振替休日・国民の休日を含む）を生徒の表・学生詳細・印刷に表示（表示だけ。判定には使わない）
- 成人の1日8時間超も確定を止める（OVER_8H）。7日40時間超は注意のまま。7日連続勤務はチェックしない
- 生徒画面: 見出しの横に大きく「未確定／確定済」、確定で止めたら「確定できません。」の後に理由。前月未確定・実績確認の進み具合は出さない。提出履歴は見出しつき・行を押すとその月を開く
- 管理画面: 生徒モードは生徒A 1人・押すと即切替・ページ下部のボタン。管理者を追加は画面から外した。設定の名前は「入力期限設定・長期休業設定・その他 設定」。学生詳細で生徒の入力内容（予定・実績）を表で見られる
- 公開中の版は @22（同じ URL）

**次にやること**

- 利用者が引き続き試す。気になる点を直す
- この枝の変更（rahiseko-alt/4aischool-shift#4）を main に取り込む

**未解決の問題**

- 追加した4言語とネパール語・ベトナム語の訳は話者の確認が必要
- スマホで表の右が切れる件は手元で再現せず、対策のみ入れた（利用者の機種で確認が必要）
- 「入力内容に問題があります」の原因は不明のまま（日付つきの理由表示を入れた）
